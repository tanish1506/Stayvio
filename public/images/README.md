# Stayvio Static Images

This folder contains static images for the Stayvio platform:

- `logo.png` - Main Stayvio logo
- `default-avatar.png` - Default user profile picture
- `placeholder.jpg` - Placeholder for listings without images
- `favicon.ico` - Browser tab icon

## Note:
Listing images uploaded by users are stored in Cloudinary, not here.
This folder is only for platform UI assets.
